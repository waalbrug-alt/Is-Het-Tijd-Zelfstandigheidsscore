# Is-Het-Tijd-Zelfstandigheidsscore
Een quiz van 12 vragen (mobiliteit, geheugen, medicatie, financiën, veiligheid, en je eigen onderbuikgevoel). Vragen verschijnen één voor één met een voortgangsbalk, en aan het eind krijgt de gebruiker een stoplicht-uitslag (groen/geel/rood) met een persoonlijke interpretatie. Daaronder de email capture voor het volledige rapport.
